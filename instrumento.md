## Preguntas

**1. ¿De qué carrera eres?**
Software / Finanzas / Auditoría / Educación / Enfermería / Fisioterapia / Agropecuaria / Agronegocios / Psicología / Otras

**2. ¿Qué sistema operativo tiene tu celular?**
Android / iOS / Otro

**3. ¿Cómo entras más al aula virtual?**
Navegador del celular / App oficial de Moodle / Computadora

**4. ¿Has usado la app oficial de Moodle?**
Nunca la he usado / La instalé y la sigo usando / La instalé y la dejé de usar

**5. Si la dejaste de usar o no la usas, ¿por qué?** (selección múltiple)
No supe configurar la URL del servidor / No pude iniciar sesión / Es lenta o confusa / Prefiero el navegador / No aplica

**6. Desde el celular, ¿con qué frecuencia te pasa esto?** (escala 1 = Nunca, 5 = Siempre)
- La página carga lenta
- El contenido se ve mal
- Tengo problemas para iniciar sesión
- No me llegan avisos de tareas

**7. ¿Qué tan de acuerdo estás?** (escala 1 = Nada, 5 = Totalmente)
- El acceso móvil actual es fácil de usar
- Necesito una app con la URL de la ULEAM ya configurada
- Usaría esa app si existiera
